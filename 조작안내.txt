Protocol Aer — 레이더 지도 프로토타입

Unity 6000.3.24f1로 제작한 Windows 실행판입니다.

[실행]
ProtocolAer.exe를 실행하세요. 실행 파일과 ProtocolAer_Data, UnityPlayer.dll 등은 같은 폴더에 있어야 합니다.

[흐름]
타이틀 → 단말 연결 → 조작 안내 / 별도 튜토리얼 → 레이더 지도
명칭 찾기 4개 → 일조 복원 → 명칭 찾기 4개 → 강수 복원 → 종료
지도에서 ??? 꼬리표와 점멸점이 있는 건물을 클릭하세요.
명칭을 4개 찾으면 지도 오른쪽 아래에서 날씨 복원을 선택할 수 있습니다.
다른 건물은 현재 복원 대상을 마쳐야 활성화됩니다.

[미노]
지역은 명칭 찾기 건물 기준입니다.
1~2지역: O만 사용 / 3지역: L 추가 / 5지역: I 추가
7지역: O/L/S만 제공. S는 덮은 네 칸을 그중 가장 낮은 높이로 통일
8지역: O/T만 제공. T는 덮은 네 칸을 그중 가장 높은 높이로 통일
마지막 강수 복원에서는 O/L/I/S/T 모두 다시 사용할 수 있습니다.
기준은 O/L/I만 겹쳐 만든 효과 적용 전 높이이며, 빈 칸 0도 포함합니다.
S와 T가 함께 덮은 칸은 원래 높이를 유지합니다.
배치 순서에 영향받지 않으며 효과끼리 연쇄 적용하지 않습니다.
S끼리 겹치면 더 낮은 후보, T끼리 겹치면 더 높은 후보를 적용합니다.
S/T 자체는 높이 +1을 만들지 않습니다. 일반 미노의 다른 칸까지 바꾸지 않습니다.
빨간 짧은 선은 낮아진 칸, 노란 두 줄은 높아진 칸입니다.
T로 새로 생긴 3D 층은 연노랑으로 표시됩니다.
O/L/I는 덮는 칸마다 +1입니다.
해금된 미노는 개수 제한 없이 사용할 수 있습니다. 오른쪽에는 종류만 표시됩니다.
새 미노가 처음 등장하는 지역에서는 그 미노의 효과를 활용해야 통과합니다.
급수 관리소는 I를 세로로 회전하는 조작을 남기고 나머지 방향 조합을 단순화했습니다.
명칭은 완벽 재현, 날씨는 재현도 85% 이상이 필요합니다.

[조작]
오른쪽의 블록 모양을 직접 클릭 → 중앙 배치판에 클릭해서 놓기
블록을 든 채 배치판 위에서 움직이면 놓기 전의 예상 입체 결과가 표시됩니다.
회전·대칭과 S/T 효과도 예상 결과에 반영되며, 클릭하기 전에는 배치가 확정되지 않습니다.
놓을 수 없는 칸이나 보드 밖 빈 공간을 클릭하면 들고 있는 블록이 반환됩니다.
일반 미노 높이를 합산한 뒤 S/T의 최소·최대 통일을 적용합니다.
빈손으로 이미 놓인 블록 클릭: 집어서 이동
우클릭 / Esc: 들고 있는 블록 반환
Q / E / R: 회전, F: 대칭 (튜토리얼의 정사각형은 모양이 변하지 않습니다)
Ctrl+Z / 되돌리기: 마지막 배치 취소
초기화: 현재 문제 처음부터

왼쪽 입체 화면 드래그 / WASD: 가로·세로 360도 시점 회전
위아래 각도 제한 없이 끝까지 돌릴 수 있습니다. 시점 초기화로 기본 방향으로 돌아갑니다.
마우스 휠: 확대·축소
3D 보드의 하늘색 모서리는 2D 배치판 아래쪽에 해당합니다. 회전해도 같은 모서리를 표시합니다.
목표만 / 현재만 / 겹쳐 보기: 입체 비교 방식
3D 미리보기는 반투명이며 목표는 윤곽선으로 표시됩니다.
목표의 흰 선은 표면이 꺾이는 모서리이며, 같은 평면의 블록 이음새는 생략됩니다.
실행에 성공한 경우에만 블록이 불투명하게 채워집니다.
배치판에는 숫자를 표시하지 않습니다. 가장 위에 놓인 미노의 색이 표시됩니다.
O / L / I / S / T: 분홍 / 하늘빛 / 연보라 / 코랄 분홍 / 연노랑
힌트: 현재 배치에서 빠진 예시 해법의 다음 미노를 종류·방향에 맞춰 선택합니다.
금색 테두리는 놓을 위치, 금색 점은 클릭할 기준 칸입니다.
빨간색 미노와 빨간 점은 먼저 옮기거나 반환할 블록입니다.
같은 힌트를 반복해서 눌러도 배치 전에는 다음 단계로 넘어가지 않습니다.

원하는 만큼 블록을 놓고 '실행'을 누르세요.
틀려도 배치는 남고, 자유롭게 수정할 수 있습니다.
시간 제한이나 시도 횟수 제한은 없습니다.
저장 기능은 없습니다. 게임을 종료하면 모든 진행 기록이 사라집니다.
