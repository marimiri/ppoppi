Protocol Aer v0.4.2 — 급수 관리소 완화 / S·T 최소·최대 통일
환경: Windows / Unity 6000.3.24f1 / 1440x900 / Direct3D 11

[확정 규칙]
- O/L/I의 +1 높이를 합산한 원래 높이를 기준으로 계산
- S: 자신이 덮은 4칸을 그중 최솟값으로 통일
- T: 자신이 덮은 4칸을 그중 최댓값으로 통일
- 빈 칸 0도 최솟값/최댓값에 포함
- S/T 공통 칸: 효과 적용 전 원래 높이 유지
- 같은 종류끼리 겹치면 S는 더 낮은 후보, T는 더 높은 후보
- 배치 순서 무관, 연쇄 없음, 중복 미노 효과 반복 증폭 없음
- T가 만든 새 층은 연노랑 표시, S는 상단 층을 제거
- 이전 전체 미노 반전 / 두 배 / -2 규칙 제거

[목표 조정]
- 명칭 1~5, 튜토리얼, 첫 날씨 유지
- 급수 관리소: O 3개/L 1개/I 1개. I 하나는 세로 회전 유지
- 앞 기록 보관소의 4개보다 하나 늘고, 예전 여러 L/I 회전 조합을 단순화
- 급수 관리소: 20복셀 / 최대 3층 / 13칸
- 바람길: 일반 3개 + S 1개, 최소 통일 소개
- 환경 제어실: O 2개 + I 1개 + T 1개, 최대 통일 소개
- 마지막 날씨: 일반 4개 + S/T 각 1개, 16복셀 / 최대 3층
- 마지막 S/T 공통 칸 2개의 원래 높이 보존. 두 효과를 각각 빼면 85% 미달
- 명칭 100%, 일조 85% / 마지막 강수 90%, 비날씨 수량 제한 / 날씨 무제한, 저장 없음 유지

[규칙 검사]
- 전체 13개 참고 해법, 해금 순서와 새 효과의 실질 활용
- 빈 칸의 0 처리 / 효과가 발자국 밖에 전파되지 않음
- T가 빈 칸에 만드는 층의 실제 3D 메시와 연노랑 출처
- 원래 높이가 0/1/2인 공통 칸 보존
- 일반 미노/연산 미노 배치 순서를 뒤집어도 같은 높이
- 연산 미노 중복 배치가 높이를 추가 생성하지 않음
- 전 스테이지의 최종 높이 합과 렌더링 복셀 개수 일치

[실행 검사]
- 실제 힌트/클릭 기준 칸으로 전체 스테이지 해결
- 최소/최대 미리보기, 이동/회전/대칭, 잘못된 배치 반환
- 중복 해법 미노, 빨간 제거 힌트, 되돌리기
- 네 방향 원근, 앞면 기준선, 80% 미리보기 / 성공 시 불투명 표시

[환경 제어실 O/I/T 구성]
- 해법: O 2개, I 1개, T 1개. 제공: O/I/T
- I가 아래쪽 가로 네 칸을 만들고 T가 위쪽 높이를 통일
- 예시 해법에서 O/I/T 중 어느 종류를 빼도 클리어되지 않음
- 최대 2층, 16복셀, 예시 4개 배치 유지
- 추가 미노 강제 조건 없이 기존 T 소개 조건과 100% 판정 유지
- 다른 스테이지의 제공 종류와 목표는 변경 없음
