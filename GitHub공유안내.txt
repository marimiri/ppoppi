Protocol Aer — GitHub 공유 안내

[소스 올리기]
1. GitHub에서 ProtocolAer 이름의 새 저장소를 만드세요.
2. 저장소의 파일 업로드 기능으로 이 폴더의 내용을 올립니다.
   Assets / Packages / ProjectSettings / Tools / docs / README.md / 조작안내.txt / .gitignore / .gitattributes
   Assets 안의 .meta 파일도 반드시 함께 올리세요.
3. 변경 사항을 커밋하면 공유할 저장소 주소가 생깁니다.

ZIP만 통째로 올리는 것보다 압축을 푼 프로젝트 파일을 올리는 편이 소스 확인과 공동 작업에 편리합니다.
이 공유 폴더에는 Unity가 다시 만드는 Library/Temp/Logs와 Windows 실행 파일을 넣지 않았습니다.

[실행판 함께 배포하기]
저장소의 Releases에서 새 릴리스를 만들고 ProtocolAer-Windows.zip을 첨부하세요.
플레이할 사람은 실행판 ZIP을 전체 압축 해제해 ProtocolAer.exe를 실행하면 됩니다.
소스를 수정할 사람은 저장소를 내려받아 Unity 6000.3.24f1로 열면 됩니다.

[현재 상태]
이 파일은 GitHub 업로드용으로 준비한 원본입니다. 원격 저장소에 업로드하거나 공개 게시한 상태는 아닙니다.
